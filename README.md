# Ứng dụng Quản lý công việc (Task Manager)

Dự án Fullstack quản lý công việc sử dụng Next.js, NestJS, PostgreSQL, Prisma và Docker Compose.

## 1. Yêu cầu hệ thống
- Docker Desktop (bao gồm Docker và Docker Compose)
- Git
- Node.js (v20 trở lên - nếu muốn chạy code ở chế độ dev)
